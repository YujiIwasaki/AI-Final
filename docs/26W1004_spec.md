# 仕様書：配車最適化アプリ

作成者：26W1004岩﨑悠志　／　作成日：2026/10/22

## 1. 目的（Why の要約）

サッカーチームの父兄（配車調整係）が試合会場への送迎の配車計画を自動で皆が納得するものを作成できるようにしたい。

## 2. ユーザー要求

現在は人手で計画作成しており、最適=総移動距離が最小になっていることは確認していない。  
また、車を出す人、出さない人それぞれへの納得感が欠けており、ロジックを標準化し、再現性がある計画を作成したい。  
1分以内に作成し、各車の移動距離、各同乗者の費用負担額も計算できるようにする。


## 3. 入力データ

固定；各選手の名前、自宅住所  
都度変動；試合会場住所、各選手の参加可否、車出し可否、乗車可能人数

## 4. 機能と受入基準

必要機能  
・各選手の名前と住所を入力、記録、表示させる  
・試合会場の住所、駐車可能台数を入力する  
・選手の名前一覧から、各選手の参加可否、車出し可否、乗車可能人数（運転手と自分の子供を除いた人数）を入力する  
・ルート計算は拠点間の直線距離ではなく、走行する道路を考慮した移動距離とする
・計算は片道で行う
・出発点は運転手の自宅、ゴールか試合会場とする
・以下の条件の中で配車計画を作成する  
     ・全ての車の移動距離の合計が最小になるように、誰が車と出し、どの家を回って子供を乗せるのかを算出する
     ・車出しする台数=駐車可能台数となる
     ・各車が、乗車可能人数≧乗せる子供の人数となる
     ・マルチ巡回セールスマン問題で最適解が有限時間に求まらない場合は、1分以内に算出可能か近似解でも可
・配車ルートを車ごとに地図上に表示し、その子が乗った区間の往復移動距離も表示する  
・乗車可能人数の合計が、参加選手数の合計を下回る場合など、配車計画が作成できない場合はエラーメッセージを表示する  
・アプリはスマホからもPCからも動かせる  
・個人情報はWeb上に公開しない  
・無料で使える範囲のサービスを組み合わせて実現する
・渋滞は考慮しない

受入基準  
・テスト用のサンプルデータを作成し、そのデータで定員超過がなく、全員が割り当てられる  
・同じ条件で計画を作成した場合は、同じ結果になる（再現性がある）  


## 5. やらないこと
車を出した回数による重みづけ  
渋滞の考慮  
LINE との連携  
ガソリン代の支払い・精算そのもの  

## 6. あとで決めること（未定・要確認）

住所を提供してもらう方法と同意の取り方  
ガソリン代ルールの詳細

## 7. 成功を測る数字

1分以内に計画が作成できる
